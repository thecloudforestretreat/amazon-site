Borrador para staging

Política de privacidad

Este borrador describe el flujo previsto de consultas y analítica. Los datos del operador y la fecha de vigencia deben completarse antes de recibir datos públicamente.

Aún no apta para producción

Faltan los datos del responsable

Experience The Amazon se encuentra en etapa de formación. El nombre legal, jurisdicción y datos de contacto del operador responsable se incorporarán antes de publicar esta política.

Información que se recopilará

Al solicitar ayuda podemos recopilar nombre, correo, fechas, número de viajeros, destinos, preferencias y mensaje. WhatsApp y el correo también procesan datos según sus propias políticas.

Para qué se utilizará

Los datos se utilizarán para responder, entender el viaje, recomendar servicios, mantener registros, prevenir abuso y mejorar el sitio. No enviaremos el contenido de formularios a Google Analytics.

Analítica y atribución

La analítica opcional se activa únicamente después del consentimiento en producción. Podemos guardar parámetros de campaña y la página de entrada para conocer el origen de las consultas. La primera versión no utiliza publicidad personalizada.

Proveedores

Los proveedores previstos incluyen Cloudflare para alojamiento, seguridad y correo; Brevo para gestionar leads y entregar correos; Google Tag Manager y Google Analytics para analítica con consentimiento; y WhatsApp cuando el visitante lo elige.

Conservación y derechos

El plazo de conservación, el procedimiento de solicitudes y los derechos aplicables se completarán junto con los datos del operador. Los visitantes podrán solicitar acceso, corrección o eliminación.

Contacto

Contacto de privacidad: info@experiencetheamazon.com. El correo debe activarse antes del lanzamiento.
